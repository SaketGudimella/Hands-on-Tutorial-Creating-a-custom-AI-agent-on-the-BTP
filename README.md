# Hands-on Tutorial: Creating a Custom AI Agent on SAP BTP

This repository provides a hands-on tutorial for building a custom AI agent on **SAP Business Technology Platform (BTP)**.

The tutorial demonstrates an end-to-end approach to developing an AI agent, exposing it through REST APIs, and building a user interface to interact with it.

## Repository Structure

### 1. Notebooks

Contains notebooks used to develop and experiment with the AI agent and its underlying functionality.

### 2. Cloud Foundry REST API

Demonstrates how to expose and interact with the AI agent through REST APIs deployed on the SAP BTP Cloud Foundry environment.

### 3. User Interface

Contains the components required to create a user interface for interacting with the custom AI agent.

## What You Will Learn

* Building a custom AI agent on SAP BTP
* Working with AI/LLM capabilities
* Developing and exposing REST APIs
* Deploying applications on SAP BTP Cloud Foundry
* Connecting an AI backend with a user interface
* Creating an end-to-end AI application on SAP BTP

## Technologies

* SAP Business Technology Platform (BTP)
* SAP BTP Cloud Foundry
* AI / Large Language Models
* REST APIs
* Python / Jupyter Notebooks
* User Interface development

## Purpose

This repository is intended as a practical reference for developers learning how to build and integrate custom AI-agent solutions within the SAP BTP ecosystem.
